# Support

Pineboard is maintained on a best-effort basis. There is no SLA and no private support channel.

| Need | Where |
|---|---|
| Installation and deployment | [docs/09-deployment.md](docs/09-deployment.md) |
| Configuration reference | [docs/08-configuration.md](docs/08-configuration.md) |
| Bugs and feature requests | [GitHub Issues](https://github.com/hmilyld/pineboard/issues) (templates provided) |
| Security vulnerabilities | [Private advisory](https://github.com/hmilyld/pineboard/security/advisories/new), never a public issue |
| Contributing | [CONTRIBUTING.md](CONTRIBUTING.md), [AGENTS.md](AGENTS.md) |

When opening an issue, include the `version` from `/api/health`, whether it is a local or deployed Worker, and the smallest reproduction. Redact secrets, cookies, email addresses and IP addresses.
